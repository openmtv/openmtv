# How the 4x cells of each sprite bank are made (docs/hochaufloesend.md,
# section 3c; first proposal from the survey of stage 1, 2026-10-16, see
# docs/hochaufloesend-messung.md).  Read by the HR display from stage 2 on.
#
#   RES  RULE  [SPRITES=RULE ...]
#
# RES: the resource number of the sprite bank; SPRITES: sprite indices in the
# bank, counted from 0 (as tools/rsc.py and tools/hrsurvey.py count them), a
# single one or a range A-B.  Rules:
#   nearest    every pixel 4x4 of its own colour: bars, frames, lines, tiles,
#              flat colour swatches stay exact rectangles
#   mmpx       MMPX of the sprite on its own, colour 0 transparent: pictures,
#              figures, icons
#   mmpx-wrap  MMPX in the sprite's own repetition: tiles laid side by side
#   font       from the 4x font (stage 3)
#   thin       a line one pixel thick, drawn see-through: only its middle two
#              sub-pixels opaque, the picture under it shows on both sides
#              (stage 5; a sprite one pixel high, or one with ink in column 0 only).
#              Only for lines drawn over a finished picture: a sprite that
#              paints an area line by line (bank 13: the building's sky) would
#              leave the old sub-pixels between its lines
# A bank not listed here: mmpx.
